# wickmail-android

Android WebView shell that hosts the Wickmail web management app, implemented in Kotlin with Gradle.

Scope:

- Secure WebView hosting the management origin
- Back and forward navigation, connectivity handling, external links
- Copy and share integration
- Optional biometric lock and post-MVP notifications

See [Android WebView shell design](../../docs/design/android.md) and [ADR 0013](../../docs/decisions/0013-typescript-svelte-web-app.md).

Status: not implemented.
